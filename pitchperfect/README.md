# Meco — Pitch Perfect deck

Open `index.html` through a local server (`python3 -m http.server`) — 3D models load as files.

Controls: **→ / Space / Enter / PageDown / clicker** = next build or slide · **← / PageUp / Backspace** = back · Home/End · **F** fullscreen · **K** play/pause film. Swipe and click on the screen edges work too.
Edit slides in `build.py`, then run `python3 build.py`.
